What you get

Everything between your players.

One call

lobby().join('level-1') puts everyone in a level together, moves on to the next room when one fills, and rejoins by itself after a dropped connection.

Your projects, live

Each project has its own page: players online now and over the day, rooms and who is in them, every ticket and why one was refused, and 30 days of usage.

Our relay

Avatars by distance (near players often, far ones less), messages once and in order across reconnects, a shared clock, and a binary protocol about 5 times smaller than JSON.

No server needed

List your game's sites and its pages join with no key. Have a server? It asks for tickets with your API key and decides who plays where.

Free to build

Your own machine (localhost) always joins your project's test rooms, apart from your players. Open two tabs and play.

Your engine

One ES module for the web, a module of its own for Babylon.js, a package for Unity (WebGL, the Editor and desktop builds), and raw messages for games with their own netcode.

Getting started

Online in three steps.

Sign in

Use your hawkesgames.com account at net.hawkesgames.com. Making one is free.

Make a project

Name it; its id is what your game passes as project. List your game's sites when you are ready to put it online.

Add the SDK

One import for the web, a module for Babylon.js, a package for Unity: pick yours below. All open source, MIT.

The SDKs

Pick your engine.

Open source under the MIT license. Every one joins the same rooms, so a Unity build and a web page can play together.

Web · any engine

JavaScript SDK

Rooms, lobbies, avatars, synced state, a shared clock, express frames for what can't wait, and games that keep going in a background tab. No dependencies, with TypeScript types.

import { lobby } from 'https://net.hawkesgen.ai/sdk/hawkes-net@1.mjs'

Docs · The module · Types
Babylon.js

Hawkes Net for Babylon.js

multiplayer(scene, { project, player }): everyone else as avatars played back smoothly, shared moving things, players in the background shown as away. An example you can open twice.

GitHub: hawkesnet-babylon
Unity · WebGL, Editor, desktop

Hawkes Net for Unity

Shared rooms by area, drop-in avatars and messages in C#. WebGL builds and the Editor's Play mode join the same rooms. Install it with Package Manager from the git URL, or as a tarball; the Asset Store listing is in review.

GitHub: hawkesnet-unity · Tarball
