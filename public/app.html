Developer & Engine Access

Personal API Key, Unity Package & MCP

Mint or rotate your personal hg_... key via POST /v1/users/api-key to call Hawkes Gen from cURL, the JS SDK, Unity Editor, or Claude MCP.

cURL Example
curl -X POST https://hawkesgen.com/v1/jobs \
  -H "Authorization: Bearer hg_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"tool":"image.generate","params":{"prompt":"A glowing obsidian crystal"}}'
JavaScript SDK (/client/hawkesgen.mjs)
import { HawkesGen } from 'https://hawkesgen.com/client/hawkesgen.mjs';
const gen = new HawkesGen({ url: 'https://hawkesgen.com', key: 'hg_YOUR_KEY' });
const job = await gen.run('image.generate', { prompt: 'Seamless sci-fi hull plating', seamless: true });
Unity Editor (com.hawkes.gen)
// Unity Editor: Window > Hawkes Gen -> Server: https://hawkesgen.com | API Key: hg_YOUR_KEY
