01 — For game developers

Made for how games are built.

Not pictures to download and fix up. Assets in the shapes engines want, with the boring parts done: slicing, transparency, tiling, palettes, maps, loops.

Sprite sheets, already sliced

A character and a motion become a transparent atlas, its frame data, and in Unity a looping AnimationClip.

On-model variations

Fire, ice and poison versions. Palette swaps, outfits, weapons. The character stays the character.

Pixel art in seconds

Any image to a set size and palette with a 1 px outline. Trims, flips, power-of-two padding: 2 credits, no GPU.

Materials that drop in

Seamless textures with normal and roughness maps, set up as a Material for URP, HDRP or Built-in.

Sound for every event

Have your agent read the player controller and make every sound it needs: hits, steps, UI, voices, music loops.

02 — Unity

Hawkes Gen for Unity.

A window in the Unity Editor. Pick an image from your project, describe what you want, watch the progress bar. Results arrive as real Unity assets, selected in the Project window.

  • Sprite sheets sliced into Sprites, with a looping AnimationClip
  • Materials for URP, HDRP or Built-in, with normal maps
  • Skyboxes as Skybox Materials · sounds as AudioClips
  • Edits, background removal and pixel art on your own textures
  • Sign in with your browser · a daily spending limit · Unity 2022.3+

07 — API

Your pipeline, not ours.

Everything in the app is an HTTP call, and an MCP server: connect Claude Code, Cursor, VS Code or Claude at hawkesgen.com/connect and ask for assets in plain words. Or make a key and call it from build scripts, tools or your engine.

REST

POST /v1/jobs to start, GET /v1/jobs/:id or the /v1/events stream to follow, /v1/assets/:id/file to download. POST /v1/run starts one and waits.

curl https://hawkesgen.com/v1/billing/quote \
  -H "Authorization: Bearer hg_…" \
  -d '{"tool":"audio.sfx","params":{"prompt":"door creak"}}'

JavaScript

One file, no dependencies, for the browser and Node.

import { HawkesGen } from 'https://hawkesgen.com/client/hawkesgen.mjs';
const gen = new HawkesGen({ url: 'https://hawkesgen.com', key });
const job = await gen.run('audio.sfx', { prompt: 'door creak' });
