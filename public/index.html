04 — Multiplayer

Hawkes Net: multiplayer for web games.

The networking every game here runs on, for yours too. Sign in with this account at net.hawkesgen.ai, make a project, and your game is online: players, rooms and tickets live on its page.

  • One call: lobby().join('level-1') puts everyone in a level together, and rejoins by itself
  • Our relay: interest by distance and a binary protocol about 5 times smaller than JSON
  • Your projects, live: players online, rooms and who is in them, tickets and usage
  • Web, Babylon and Unity WebGL: one SDK; free to build and test on localhost
  • Already in Sick Of It, Yooba Land and Dose Of Destruction
Open Hawkes Net See how it works
Measured on our load test: 1,000 players on one relay node with 4 processes, none dropped, about 8 KB/s each.

09 — API

Your pipeline, not ours.

Everything in the app is an HTTP call, and an MCP server: connect Claude Code, Cursor, VS Code or Claude at hawkesgen.ai/connect and ask for assets in plain words. Or make a key and call it from build scripts, tools or your engine.

REST

POST /v1/jobs to start, GET /v1/jobs/:id or the /v1/events stream to follow, /v1/assets/:id/file to download. POST /v1/run starts one and waits.

curl https://hawkesgen.ai/v1/billing/quote \
  -H "Authorization: Bearer hg_…" \
  -d '{"tool":"audio.sfx","params":{"prompt":"door creak"}}'

JavaScript

One file, no dependencies, for the browser and Node.

import { HawkesGen } from 'https://hawkesgen.ai/client/hawkesgen.mjs';
const gen = new HawkesGen({ url: 'https://hawkesgen.ai', key });
const job = await gen.run('audio.sfx', { prompt: 'door creak' });
