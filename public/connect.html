01 — Add it

One click, or one line.

Every option uses the same address. Your editor opens a hawkesgen.com sign-in the first time.

Anthropic

Claude Code

Add it, then run /mcp in Claude Code to sign in.

claude mcp add --transport http hawkesgen https://hawkesgen.com/mcp
Cursor

Cursor

Opens Cursor's install dialog. Then click Connect next to hawkesgen in Cursor's MCP settings.

Add to Cursor
Microsoft

VS Code

For GitHub Copilot's agent mode. VS Code asks you to trust it, then signs you in.

Install in VS CodeVS Code Insiders
Anthropic

Claude app

Copies the address and opens Connectors in the Claude desktop app (or on claude.ai in your browser); then Add, paste, Connect.

Add to Claudeclaude.ai
On the Connectors page that just opened
  1. + Add (top right) → Add custom connector
  2. Name it Hawkes Gen, paste the address (it's on your clipboard), click Add
  3. Connect, then approve on hawkesgen.com
https://hawkesgen.com/mcp

No Claude app? Open claude.ai/customize/connectors instead. In the app it's Customize → Connectors.

In Claude Code (the Code tab)

Paste this into a Claude Code session. It adds the server to your settings; then run /mcp and choose hawkesgen to sign in.

Add an MCP server named hawkesgen, HTTP transport, URL https://hawkesgen.com/mcp, at user scope (claude mcp add --transport http --scope user hawkesgen https://hawkesgen.com/mcp).
Codeium

Windsurf

Add this to ~/.codeium/windsurf/mcp_config.json, then refresh MCP servers.

{"mcpServers":{"hawkesgen":{"serverUrl":"https://hawkesgen.com/mcp"}}}
OpenAI

ChatGPT

With developer mode on: Settings → Apps & Connectors → Create. Paste the address and choose OAuth.

https://hawkesgen.com/mcp
Anything else

With an API key

For tools without OAuth, and for CI: make a key in the studio and send it as a header.

{"mcpServers":{"hawkesgen":{"url":"https://hawkesgen.com/mcp","headers":{"Authorization":"Bearer hg_…"}}}}
