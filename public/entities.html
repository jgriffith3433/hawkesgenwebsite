Entity codex

Everything in a Hawkes game is a thing in its world: one JSON object in the game's scene.json, with a shape, a look, a way of moving and things it does on its own. These are the types the engine builds. The window below is the same engine the editor runs, so edit a spec and apply it.

What it does on its own

Behaviors, in the words people use. Give a thing any number of them; tell the assistant "make it spin" or "the door should open when I get close" and it picks them. Games can add their own in a behaviors/ file.

Made for you by Hawkes Gen

Ask the assistant (or press a button) and Hawkes Gen makes the file on its GPUs, pays for it from your credits, and adds it to the game's assets. Then an entity uses it by name.
